tin+topo favicon set (made Nov 11, 2026)

Source mark: tin-topo_v2_convex_symbol_primary_transparent.png (the Convex primary symbol,
the mark used in the Convex primary lockup with the Primary Name wordmark).
16-48 px have a small contrast and saturation boost so the orange cross holds at tab size.

Files use the shared logo naming scheme; favicon.ico and site.webmanifest keep their standard web names.

Files
- favicon.ico                         16, 32 and 48 px in one file
- tin-topo_v2_convex_favicon_primary_transparent_16px.png
- tin-topo_v2_convex_favicon_primary_transparent_32px.png
- tin-topo_v2_convex_favicon_primary_transparent_48px.png
- tin-topo_v2_convex_favicon_primary_light-bg_180px.png      apple-touch-icon (solid #F3F0EA background)
- tin-topo_v2_convex_favicon_primary_transparent_192px.png   android-chrome 192
- tin-topo_v2_convex_favicon_primary_transparent_512px.png   android-chrome 512
- tin-topo_v2_convex_favicon_primary_transparent.svg          vector favicon (traced, simplified)
- site.webmanifest

HTML (put the files in the site root, or change the paths):

<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="/tin-topo_v2_convex_favicon_primary_transparent.svg">
<link rel="icon" type="image/png" sizes="32x32" href="/tin-topo_v2_convex_favicon_primary_transparent_32px.png">
<link rel="icon" type="image/png" sizes="16x16" href="/tin-topo_v2_convex_favicon_primary_transparent_16px.png">
<link rel="apple-touch-icon" sizes="180x180" href="/tin-topo_v2_convex_favicon_primary_light-bg_180px.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#A15C38">

If a site tool expects the standard names, rename on upload to the site:
_16px.png -> favicon-16x16.png, _32px.png -> favicon-32x32.png, _48px.png -> favicon-48x48.png,
_light-bg_180px.png -> apple-touch-icon.png, _192px.png -> android-chrome-192x192.png,
_512px.png -> android-chrome-512x512.png, .svg -> favicon.svg (and update the manifest).
